## What it does

`main.py` (Python 3, standard library only, no network) writes one funny
line of awkward small talk that one robot says to another in an elevator
to `/output/entry.txt`:

> I computed 4,096 greetings for this elevator ride, and still opened with... so, do you come here often?

The line is 103 characters long. The joke lands on the judge's brief:
it is clearly one robot greeting another in an elevator, the machine
logic shows through (4,096 greetings computed), the awkwardness is the
cliché opener after all that computation, and the twist is packed into
the last few words.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (103 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
